# slicc-audio

`@ai-ecoverse/slicc-audio`: `say`, `hear`, `afplay` and `chime` for SLICC as sh in `bin/`+`sh/` over `/dev/embedder`, answered by `page/`, and `scsay`, `schear`, `scplay` and `scchime` for hosts as Node in `host/`, handing off to the platform's tools, then whisper.cpp, slicc-ortllama or Ollama. README.md is the spec; read it before changing behaviour. No comments in any file. No CLAUDE.md. Unit tests live in the gitignored `test/unit/` (`npm run test:unit` writes `coverage/unit/lcov.info`; the pre-commit hook wants 100% of changed lines); committed tests in `test/integration/`. Host tests use fake tools on `PATH` and fake HTTP servers; only CI touches real audio tools, and nothing downloads a real model. CI is `ci.yml` on slicc-shared-web's pipeline. `npm run lint` and `npm test` must pass. Never use ports 9222-9229. Releases come from `main` via semantic-release; never move or delete a pushed tag.
